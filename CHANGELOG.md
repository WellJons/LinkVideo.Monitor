# LinkVideo Monitor 0.7.6 Beta

- Исправлена гонка поколений процесса: завершение старого FFmpeg больше не сбрасывает состояние уже запущенного нового потока после быстрого перезапуска.
- Защищён локальный веб-интерфейс: изменяющие состояние запросы требуют POST и фирменный заголовок, проверяется loopback-адрес и Host; устранён CSRF со сторонних сайтов.
- При занятом порту 8098 приложение проверяет подлинность уже запущенного LinkVideo Monitor и больше не передаёт приватную ссылку подключения постороннему локальному процессу.
- `SetThreadExecutionState` перенесён на постоянный закреплённый поток Windows, поэтому запрет сна и его отмена теперь выполняются на одном OS thread.
- Обновление heartbeat защищённого захвата стало атомарным: служба больше не видит ложное исчезновение запроса и не перезапускает агент UAC/Winlogon.
- Ужесточена проверка запросов к системной службе: проверяются session ID, PID, имя процесса, точное имя shared-memory, возраст и размер файла.
- Сырые GDI-кадры и PCM-звук теперь гарантированно записываются полностью даже при частичном `Write`.
- Запись кадра в FFmpeg больше не удерживает блокировку состояния захвата, поэтому событие блокировки Windows не задерживается зависшим pipe.
- Настройки сохраняются атомарно; повреждённый конфиг не перезаписывается значениями по умолчанию при автозапуске.
- Установщик и обновление MediaMTX заменяют файлы атомарно, не удаляя рабочую версию до успешной замены.
- Исправлен отложенный перезапуск после сна: остановленный пользователем поток больше не запускается обратно.
- Неподдерживаемая дистанционная команда больше не помечается выполненной; размер ответа API ограничен.
- Убран оставшийся `CAPTUREBLT` из резервного кода предпросмотра.

## 0.7.0 Beta

## Защищённый рабочий стол и UAC

- Добавлена системная служба `LinkVideoMonitorCapture`, работающая от `LocalSystem`.
- Служба запускает отдельный GDI-агент в активном сеансе на `winsta0\Winlogon`.

- FFmpeg, кодировщик и RTSP/RTMP-соединение остаются в основном процессе и не перезапускаются при переходе на UAC.

## Защита конфиденциальных данных

- Убрано скрытие всех `Edit` и `ComboBox` элементов.
- Всегда скрываются элементы с `UIA_IsPassword=true`.
- Для обычных полей применяется строгая проверка названия, AutomationId, класса, HelpText и ARIA-метаданных.
- Добавлены пароли, PIN, одноразовые коды, CVV/CVC, номера карт, банковские и паспортные реквизиты, API-ключи и токены.

## Кодировщики

- Аппаратный кодировщик проверяется на фактическом разрешении и FPS трансляции.
- Выбранный автоматически кодировщик закрепляется и не меняется при сетевом переподключении.
- Убрана ложная блокировка GPU из-за общего сообщения `Error while opening encoder`.
- Переход на `libx264` происходит только после аппаратно-специфической ошибки.
- После подтверждённой ошибки аппаратный кодировщик получает период ожидания 30 минут; после повторной ошибки — 2 часа.
- Для NVENC, QSV и AMF используется входной формат NV12.

## Установка

- Установщик сохраняет прежний простой интерфейс.
- Для установки системной службы отдельно запрашиваются права администратора.
- Служебный EXE размещается в `%PROGRAMDATA%\LinkVideo.Monitor\Service`.
- Деинсталлятор удаляет службу, агент, session-файлы и данные предыдущих версий.
