# Пошаговый установщик LinkVideo Monitor

Установщик и деинсталлятор выполнены как отдельные оконные мастера в стиле LinkVideo:

- адаптивная приветственная страница с карточками преимуществ;
- краткие минимальные системные требования;
- обязательное принятие пользовательского соглашения;
- выбор ярлыка; автозапуск вместе с Windows настраивается автоматически;
- видимый прогресс установки и обновления;
- итоговый экран с запуском программы;
- отдельный пошаговый деинсталлятор с выбором удаления настроек и журналов;
- плавная приветственная анимация без дёргания остальных страниц;
- многоразмерная иконка приложения, установщика и деинсталлятора.

Win32-мастер закрепляет интерфейс за одним OS-потоком. Копирование файлов, установка службы и удаление выполняются в рабочей горутине, поэтому окно продолжает обрабатывать сообщения Windows.

`payload.zip` временно создаётся командой:

```bat
scripts\windows\build-release.cmd
```

Сначала собирается `Uninstall.exe`, затем он вместе с приложением, FFmpeg и документацией помещается внутрь однофайлового установщика. После сборки временный `installer/payload.zip` удаляется.
