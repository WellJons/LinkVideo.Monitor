# Цифровая подпись и издатель

В оригинальном `setup.exe` обнаружена Authenticode-подпись организации `OOO Oblachnoe Videonablyudenie` (ООО «Облачное видеонаблюдение»), выпущенная цепочкой GlobalSign EV Code Signing.

Публичный сертификат можно извлечь из оригинального файла, но им нельзя подписать новую сборку. Для появления исходного издателя в окне UAC и SmartScreen требуется закрытый ключ правообладателя либо новый действующий сертификат организации.

Перед публикацией разработчики должны подписать как минимум:

- `LinkVideo.Monitor.exe`;
- `LinkVideo.ScreenOverlay.exe`;
- `LinkVideo.AudioLoopback.exe`;
- итоговый установщик.

Пример команды (параметры сертификата и сервера меток времени предоставляет правообладатель):

```cmd
signtool sign /fd SHA256 /td SHA256 /tr <TIMESTAMP_URL> /f <CERTIFICATE.pfx> /p <PASSWORD> LinkVideo.Monitor.exe
```

В текущей сборке поле Publisher в списке установленных программ задано как ООО «Облачное видеонаблюдение», но доверенный издатель в UAC появится только после реальной Authenticode-подписи.
