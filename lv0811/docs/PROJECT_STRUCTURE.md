# Структура проекта

```text
LinkVideo.Monitor/
├── cmd/linkvideo-monitor/       основное приложение (package main)
├── installer/                   исходник однофайлового установщика
├── assets/icons/                иконки приложения
├── api/                         OpenAPI удалённого управления
├── docs/                        техническая документация
├── licenses/                    пользовательское соглашение
├── scripts/windows/             сборка и тесты
├── third_party/ffmpeg/bin/      FFmpeg runtime через Git LFS
├── tools/                       вспомогательные инструменты
├── build/                       локальные результаты сборки, не коммитятся
├── go.mod                       модуль основного приложения
└── go.work                      рабочее пространство основного и installer-модулей
```

## Почему Go-файлы приложения находятся в одной папке

Сейчас основной EXE реализован одним пакетом `main`: обычное приложение, GDI/DXGI-захват, звук, служба UAC и вспомогательные режимы используют общие типы и состояние. Файлы сгруппированы по префиксам, но не разнесены по подпакетам, чтобы передача проекта не сопровождалась рискованной архитектурной переработкой.

Рекомендуемое дальнейшее разделение после стабилизации:

- `internal/capture`;
- `internal/encoder`;
- `internal/audio`;
- `internal/privacy`;
- `internal/securedesktop`;
- `internal/remote`;
- `internal/webui`.
